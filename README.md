# Animalec — Tarefa 3.1b

Back-office do Animalec com duas entidades novas: patrocinadores e especialistas.

- `Front-end_Animalec-master/` — protótipo (Vue 2)
- `design/` — wireframes e mockups (draw.io)

## Como correr

```
cd Front-end_Animalec-master
npm install
NODE_OPTIONS=--openssl-legacy-provider npm run serve
```

Abrir http://localhost:8080/admin.

Os dados de patrocinadores e especialistas ficam guardados no navegador. Os cartões do livro (utilizadores, animais, quizzes e questões) não carregam dados porque o servidor original já não está disponível.
